💡 ¿Cómo poner Audio y Video en HTML?

Para agregar contenido multimedia a tu página web sin usar programas externos o scripts complejos, HTML5 nos da dos etiquetas nativas muy sencillas:

  • Para Reproducir Audio (<audio>): Usa la etiqueta <audio controls>. El atributo controls muestra los botones de Play, Pausa y Volumen. Dentro añades <source src="archivo.mp3" type="audio/mpeg"> para indicar dónde está guardado el archivo de música o nota de voz.
  • Para Reproducir Video (<video> o <iframe>): Si el video es un archivo local (ej. videoplayback.mp4), usa <video controls> con sus dimensiones (width y height). Si proviene de plataformas externas como YouTube o Vimeo, se utiliza la etiqueta <iframe src="...">.

GUÍA DE ETIQUETAS HTML 📚

Sintaxis y explicación de tus etiquetas solicitadas y más de 50 esenciales.

<p>

Párrafo: Define un bloque de texto general.
Sintaxis: <p>Texto</p>

<li>

Elemento de lista: Define un ítem dentro de listas (<ul> o <ol>).
Sintaxis: <li>Elemento</li>

att (Atributo)

Atributo: Propiedad dentro de etiquetas (ej: id, class).
Sintaxis: <tag atributo="valor">

<h1>

Encabezado principal: Título más importante (H1 a H6).
Sintaxis: <h1>Título</h1>

<head>

Cabecera oculta: Metadatos, título de pestaña y estilos.
Sintaxis: <head>...</head>

<html>

Raíz HTML: Contenedor principal de todo el documento.
Sintaxis: <html lang="es">...</html>

<table>

Tabla: Contenedor para crear tablas de datos.
Sintaxis: <table border="1">...</table>

<br>

Salto de línea: Rompe la línea de texto actual.
Sintaxis: <br>

<img>

Imagen: Inserta una imagen multimedia.
Sintaxis: <img src="foto.jpg" alt="texto">

<video>

Video: Reproductor de video nativo.
Sintaxis: <video controls><source src="v.mp4"></video>

<audio>

Audio: Reproductor de sonido nativo.
Sintaxis: <audio controls><source src="a.mp3"></audio>

<button>

Botón interactivo: Botón clickeable en formularios o páginas.
Sintaxis: <button>Click</button>

<input>

Campo de entrada: Entradas de texto, botones, checkboxes.
Sintaxis: <input type="text">

<select>

Menú desplegable: Lista de opciones seleccionables.
Sintaxis: <select><option>Opción</option></select>

<hr>

Línea horizontal: Separador visual de contenido.
Sintaxis: <hr>

<a> (ir)

Hipervínculo: Enlace para navegar a otras páginas o secciones.
Sintaxis: <a href="url">Enlace</a>

<label>

Etiqueta de formulario: Texto descriptivo para inputs.
Sintaxis: <label>Nombre:</label>

<menu>

Menú de comandos: Lista de opciones o comandos interactivos.
Sintaxis: <menu><li>Opción</li></menu>
